# Data

This directory holds the canonical, reviewed dataset behind Legends of League. It is the single
source of truth for the site and the simulator, and it is licensed under
[CC BY-SA 3.0](LICENSE) because it derives from [Leaguepedia](https://lol.fandom.com/).

Data enters this directory only through pull requests, generated by the ingestion CLI
(`ingest/`; see [docs/ingestion.md](../docs/ingestion.md)). See
[docs/data-model.md](../docs/data-model.md) for the schema.

| Path                               | Contents                                                                |
| ---------------------------------- | ----------------------------------------------------------------------- |
| `editions.yaml`                    | Registry of editions and where providers keep their data (hand-written) |
| `entities/`                        | Regions and tournaments (curated); organizations, teams and players     |
| `tournaments/<tournament>/<year>/` | One directory per edition: series, games, stats, rosters, results       |
| `_meta/import-runs/`               | Log of every import run that changed data                               |
| `overrides/`                       | Planned: reviewed manual corrections applied on top of provider data    |

Provider identifiers (Leaguepedia page names, match IDs) are stored as `externalRefs` on each
record. They are how imports recognize teams, players and matches they have already seen.
